# Empowered: Women in Industry — 2026 Digital Program

GitHub Pages-ready website. Upload the **contents** of this folder to the root of the `empowered-women-in-industry-2026` repository. Keep `index.html` at the root. In Settings → Pages use **Deploy from a branch**, branch `main`, folder `/(root)`.

Your live URL will be `https://YOUR-USERNAME.github.io/empowered-women-in-industry-2026/`. Test the live page on a phone before making the event QR code.
